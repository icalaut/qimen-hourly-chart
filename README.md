# 時盤 · 奇門遁甲排盤

一個可在瀏覽器中使用的奇門排盤頁面。可選擇命盤、年盤、月盤、日盤或時盤，生成四柱、節氣與局數，以及包含八神、九星、八門、天盤和地盤的九宮盤。

主盤下方會同步顯示年、月、日、時四張玄空紫白飛星圖，每宮標示一至九星數字與星名。

主盤八個外宮另按所提供「奇門穿易」教材顯示六爻本卦圖：九星以先天數取上卦（天心1、天柱2、天英3、天沖4、天輔5、天蓬6、天任7、天芮8），八門取下卦（開1、驚2、景3、傷4、杜5、休6、生7、死8）；第三數取本宮左上角方框內的玄空紫白飛星數（依盤型取年、月、日或時飛星圖該宮之數），再將上卦數、下卦數與此飛數相加除以6取餘，餘0作第六爻。宮頂顯示本卦名與自上而下的六爻線，紅點標動爻；滑過圖示可查看上／下卦、飛數計算式、互卦與變卦。中宮天禽不套用此法，因教材未說明中宮取卦規則。此為教材流派的奇門穿易算法，不代表所有奇門排盤通用。

## 使用

在專案目錄啟動靜態檔案伺服器：

```sh
ruby -run -e httpd . -p 4173
```

然後在瀏覽器開啟 `http://localhost:4173`。時盤計算庫由 jsDelivr 載入，年、月、日盤引擎與農曆日期轉換會按需從 esm.sh 載入，因此首次使用需要網路連線。

如果已安裝 Node.js 與 npm，也可執行 `npm install` 後用 `npm run dev` 啟動 Vite，或用 `npm run build` 檢查正式建置。

## 排盤口徑

- 時盤與命盤依賴 `qimen-dunjia` 3.1.x；年、月、日盤使用 `bigfishmarquis-qimen` 的對應獨立引擎。
- 时盘定局法提供拆补法与符头法 / 置闰法（超神接气）两种算法；引擎的置闰法由 `符頭` 参数实现，包含芒种、大雪的重用本气三元规则。两种定局口径的结果可能不同。
- 命盤按所填出生年月日時，以時家轉盤法生成；年、月、日盤忽略不相關的更細時間單位。
- 命盤宮位指標按用神實際落宮定位：智慧杜門、子女與父母取天盤丁（時干為甲則改取該時柱旬首遁儀）、形象景門、田宅死門、婚姻六合、因果取時柱旬首遁儀的地盤宮、遷移驛馬、地位傷門、心靈驚門、教育天輔、財帛生門、家庭休門、健康天芮、元辰取日柱旬首遁儀的天盤宮、事業開門、兄弟取天盤月干所在宮。年齡區間由出生年支對應的後天八卦宮起算（子坎、丑寅艮、卯震、辰巳巽、午離、未申坤、酉兌、戌亥乾），該宮為1–10歲，順時針每宮增加十年。
- 出行訣只在命盤模式提供：先取本命值符、九天、生門的宮位，再按節氣月盤、日盤與時盤逐層疊合；結果分為天月值符日、九天日、生門日，並列出方向與十二個兩小時時段。另按所附資料第18節，顯示掃描公曆月內各農曆月的旺方與面向，僅作方位參考、不參與擇日篩選；第19節九星出行圖與第20節星辰值日百忌可能涉及進一步擇日，但目前照片不足以準確核對其規則，暫不納入計算。
- 日家盤與時家盤顯示「大金剛神・值日百忌」資訊：按農曆日期列出二十八宿、宿值吉凶及曆書日宜忌；時盤面板為該日通用資料，不代表各時辰分別判吉凶。
- 時盤預測事項再新增遷移、囑託、合夥與求財：遷移按所選方向取宮中九星；囑託列值符與值使；合夥、求財列生門宮天地盤干及戊財，只框天盤干；均用於定位參考，不自動推斷吉凶。
- 時盤預測事項依據所提供章節擴充新任地方安否、新任官吉凶、分居、請人來否、誰去誰不去、在外問家中安否、官長喜怒、求仙、陰宅、功名與行人；按可辨認的用神列出盤中參考落點，不自動推斷吉凶。請人來否須先選來人方向；陰宅章節提到但目前八神盤未排出的神會標示未排出。
- 時盤預測事項另含壽夭、起解、解罪人與和事：壽夭列天沖、死門以供比較落宮遠近；起解列值使、六辛、開門、生門及原文提到的天蓬、天柱；解罪人須選當事人年命天干，再列六辛與開門；和事依時柱旬首及遁甲六儀定位，並列六庚、六丁、六丙供參考。這些章節涉及落宮遠近、生克、旺衰等判斷，介面只定位用神，不自動給出結果。
- 時盤預測事項另含工作犯小人、升遷與調動：犯小人列月干、時干、日干及玄武、騰蛇、白虎、太陰、六合供比對；升遷與調動列日干、開門、值符、丙、九天、依日支定位的驛馬、伏吟／反吟，並檢查開門宮是否逢日／時旬空。除驛馬與空亡定位外，盤面只列參考，不自動斷定人事結果或應期。
- 時盤與命盤按日干標出喜神、财神與天乙貴人方位：喜神採甲己艮、乙庚乾、丙辛坤、丁壬離、戊癸巽；财神採甲乙艮、丙丁坤、戊己坎、庚辛震、壬癸離；天乙貴人依日干對應地支（甲戊庚丑未、乙己子申、丙丁亥酉、辛寅午、壬癸卯巳）映射到九宮。各組第一支標為陽貴／晝貴並以紅底填滿，第二支標為陰貴／夜貴並留白。此為常見日干口徑，只標方位，不代表該宮整體吉凶；各派算法可能不同。
- 七星燈只在時盤自動分析，無需勾選目標：逐盤檢查延壽、事業、財富、健康四類教材條件；有任一命中才顯示「七星燈 · 時盤分析」。每個命中目標依其宮位方向，獨立顯示教材對應的八方七步路線圖；每一步以蜡烛点位绘制，序号标在蜡烛旁，不把不同目标路线叠在同一图上；未命中则隐藏。各目标均依同宫八神、九星、八门、天盘干及玉女守门／青龙返首／飞鸟跌穴条件判断，延寿另要求日干甲。教材未提供完整出生年份对应本命七星表，因此不推定个人本命星，也不与个人命盘挂钩。
- 个人三胜宫为命盘模式下独立的月度扫描选项，与出行诀互斥；以本命值符、九天、生门三宫为目标，按月盘、日盘、时盘教材步骤列出符合的全部日期、时辰与方向。
- 启动八神为命盘模式下独立课题，与出行诀、个人三胜宫互斥；可选择目标八神，按年盘、月盘、日盘、时盘四层同神同宫筛选启动日期与时辰，并列出目标宫位和背向方向。
- 盤面摘要只顯示無具體落宮的全盤格局，不列各宮局部組合；年、月、日盤不計算依賴時辰的格局。
- 輸入時間按 UTC+8 標準時解讀，節氣採用庫內的定氣曆法。
- 年家、月家盤按所選日期對應的立春干支年計算；月盤的月份由節氣月確定。
- 九宮標記包含四柱旬空、門克宮、宮克門、宮生門、門生宮，以及排盤引擎辨識的其他逐宮格局與十干克應。
- 另標示日奇被刑（天盤乙加地盤庚）、青龍伏吟（戊加戊）、三奇受制、奇儀相合、三奇升殿（乙震、丙離、丁兌）、奇入太陰（丁加丁）、神遁與龍遁。
- 「假遁」按五假格顯示：天假為景門、天盤三奇、九天同宮；地假為杜門、天盤丁／己／癸、九地／六合／太陰同宮；人假為景門、天盤壬、九天同宮；神假為傷門、天盤丁／己／癸、九地同宮；鬼假為死門、天盤丁／己／癸、九地同宮。各派口訣略有差異，龍遁等格局亦可能採不同條件。
- 四張玄空紫白飛星圖採年、月、日、時分層起星：年星以立春年數字和起中宮並順飛；月星依年支分組，以節氣月逆推中宮星、九宮順飛；日星依冬至、雨水、谷雨後的甲子日一、七、四順行，夏至、處暑、霜降後則九、三、六逆行；時星依冬夏至順逆及日支孟仲季分組起子時星，再逐時辰推移。不同紫白流派的起星口徑可能有異。
- 子時提供「子初換日（次日）」與「子正換日（當日）」選項。
- 未校正所在地時區、夏令時間或真太陽時。請按所採用的排盤口徑輸入時間。

## 依賴

- `qimen-dunjia`：奇門時盤計算。
- `bigfishmarquis-qimen`：奇門年盤、月盤、日盤計算。
- `lunar-javascript`：公曆轉農曆日期與時辰。
- `vite`：可選的本機開發伺服器與建置工具。
- `opencc-js`：簡體轉繁體介面文字。
